# CSA Lesson 1 — Java Study Planner & GitHub Collaboration Exercise

**Bilingual project documentation / Documentación bilingüe**

## English

### Overview

This repository preserves a collaborative learning exercise focused on Java fundamentals and the GitHub collaboration workflow. The activity guides students through repository setup, branches, commits, pushes, pull requests and code reviews while working with a small console-based study-planner project.

### Learning objectives

- Understand repositories, branches and commits.
- Clone a shared repository and publish a working branch.
- Coordinate changes with a teammate.
- Open and review pull requests.
- Practice Java classes, objects, methods and basic collections.
- Identify and correct syntax errors during a guided exercise.

### Technology

- Java 25
- Maven
- Git and GitHub
- Visual Studio Code

### Project scope and status

This is an academic exercise and learning scaffold, not a production application. The repository includes guided instructions and starter code intended to be completed during the activity. The Java implementation should be reviewed and corrected before treating it as a build-ready application; successful compilation is not claimed by this README.

### Collaboration

The exercise is designed around pair programming and GitHub collaboration. Contributions should be understood in the context of the team activity rather than presented as an independently developed product.

### Getting started

1. Clone the repository.
2. Open it in Visual Studio Code or another Java-compatible IDE.
3. Review the Maven project configuration and the lesson instructions.
4. Follow the activity to create branches, make changes, commit, push and review pull requests.
5. Correct the starter-code issues before attempting to use the study planner.

## Español

### Descripción general

Este repositorio conserva un ejercicio de aprendizaje colaborativo centrado en fundamentos de Java y el flujo de trabajo colaborativo de GitHub. La actividad guía a los estudiantes por la configuración de repositorios, ramas, commits, envíos, pull requests y revisiones de código mientras trabajan con un pequeño proyecto de planificación de estudio por consola.

### Objetivos de aprendizaje

- Comprender repositorios, ramas y commits.
- Clonar un repositorio compartido y publicar una rama de trabajo.
- Coordinar cambios con un compañero.
- Crear y revisar pull requests.
- Practicar clases, objetos, métodos y colecciones básicas en Java.
- Identificar y corregir errores de sintaxis durante un ejercicio guiado.

### Tecnologías

- Java 25
- Maven
- Git y GitHub
- Visual Studio Code

### Alcance y estado del proyecto

Es un ejercicio académico y una base de aprendizaje, no una aplicación de producción. El repositorio incluye instrucciones guiadas y código inicial que debe completarse durante la actividad. La implementación Java debe revisarse y corregirse antes de considerarla lista para compilar; este README no afirma que la compilación sea exitosa.

### Colaboración

El ejercicio está diseñado alrededor de programación en pareja y colaboración mediante GitHub. Las contribuciones deben entenderse dentro del contexto de la actividad, no presentarse como un producto desarrollado individualmente.

### Primeros pasos

1. Clona el repositorio.
2. Ábrelo en Visual Studio Code u otro IDE compatible con Java.
3. Revisa la configuración del proyecto Maven y las instrucciones de la lección.
4. Sigue la actividad para crear ramas, realizar cambios, hacer commits, enviar cambios y revisar pull requests.
5. Corrige los problemas del código inicial antes de intentar utilizar el planificador de estudio.
